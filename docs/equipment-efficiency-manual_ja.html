1. この画面でできること

設備能率管理は、設備（検査工程は検査員）と製品の組み合わせごとに、計画で使う能率と段取時間を保持するマスタです。切断・面取・成型・溶接・メッキ・検査の各計画画面は、ここにある有効な行を参照します。

画面図は 2026年10月9日の開発環境（マスタ管理 → BOM → 設備能率管理）で撮影しています。件数は撮影時点の登録内容です。

できること説明
一覧・絞り込み工程タブ、キーワード、設備、製品名で行を探す
登録・編集・削除設備と製品を選び、能率・段取時間・状態・備考を保存する
状態の切替一覧のスイッチで有効 / 無効をすぐ保存する
現在能率の更新直近 3 か月の生産性から参考値を計算し、現在能率だけを書き換える
能率への反映確認のあと、その行の現在能率を能率へコピーする
生産性から追加生産性にあって、このマスタに無い組み合わせを新規行として追加する
工程別一覧設備ごとのカードで、製品名・能率・使用材料を見る。A3 横で印刷できる
印刷 / Excelいまの絞り込み結果を、ページをまたいでまとめて出力する
能率と現在能率は別の項目です。「現在能率更新」を押しても、計画が参照する能率は変わりません。能率を変えるのは、行の「反映」、または編集画面での手入力だけです。

2. 画面を開く

  1. Smart-EMAPs にログインします。
  2. 左メニュー マスタ管理 を開きます。
  3. BOM を開きます。
  4. 設備能率管理 をクリックします。

メニューに項目が無い場合は、ロールにこの画面の参照権限が付いていません。管理者にメニュー権限の付与を依頼してください。

4. 絞り込み

4.1 キーワード

プレースホルダは「製品名・設備名で検索…」です。入力して約 0.3 秒待つと検索します。設備名、設備 CD、製品名、製品 CD、備考などに部分一致します。× で消せます。

4.2 設備

候補は「設備名（設備 CD）」です。入力して絞り込めます。× で解除できます。

  • 工程タブが「全て」以外のとき、候補はその工程の設備だけです。
  • タブを変えたとき、選んでいた設備がその工程に無ければ選択は外れます。
  • 検査員の行は、設備 CD が INSP- で始まるため、検査タブの候補に出ます。

4.3 製品名

候補は製品名と製品 CD です。設備を選んでいるときは、その設備に登録されている製品だけに絞られます。設備を変えて、選んでいた製品がその設備に無ければ、製品の選択は外れます。

工程を決めてから設備、そのあと製品、の順に選ぶと候補が一番少なくなります。

6. 新規登録・編集・削除・状態の切替

6.1 新規登録

  1. 新規登録 を押します。タイトルは「能率設定新規登録」です。
  2. 設備 を選びます。設備名は選んだコードから自動で入り、手では変えられません。
  3. 製品 を選びます。製品名も自動で入ります。
  4. 能率 を入れます。0〜10000、小数第 1 位、0.1 刻みです。必須です。
  5. 必要なら 段取時間（0〜9999 分、整数）、状態（初期値は有効）、備考 を入れます。
  6. 保存 を押します。「能率設定を登録しました」と出れば完了です。

設備または製品が空だと「設備を選択してください」「製品を選択してください」が出て保存できません。能率が空、または 0 未満でも保存できません。

6.2 編集

行の 編集 を押すと「能率設定編集」が開きます。項目は新規登録と同じです。保存すると「能率設定を更新しました」と出ます。

6.3 削除

行の 削除 を押すと「この能率設定を削除しますか？」と聞かれます。削除 で確定し、キャンセル で中止します。削除した行は元に戻せません。計画側でその組み合わせを参照している場合は、先に影響を確認してください。

6.4 状態

一覧のスイッチでも、編集画面の「有効 / 無効」でも変えられます。無効の行は工程別一覧には出ません。計画側で無効行を使うかどうかは、参照している各画面の条件に従います。

7. 現在能率を更新する

現在能率更新 は、画面に見えている行だけではなく、対象工程の登録行すべてを一度に更新します。タブや絞り込みでは範囲は狭まりません。

  1. ボタンを押します。
  2. 確認文に期間が出ます。例: 2026-10-09 に実行すると「2026-08-01 〜 2026-10-09」です。当月を含む直近 3 カレンダー月の 1 日から、実行日までです。
  3. 内容を確認し、更新 を押します。キャンセル なら何も変わりません。
  4. 完了すると次の件数が表示されます。
表示意味
算出期間内の実績から現在能率を書き込んだ件数
実績なし対象工程だが、一致する実績が無く、現在能率を空にした件数
対象外計算しない工程の件数。メッキはここにはいり、値は変わりません
確認文の要点: 実績数 ÷ 作業時間を、製品と設備（検査は検査員）ごとに集計し、95% を現在能率へ書く。能率そのものは変わらない。メッキは集計対象外。

8. 現在能率を能率へ反映する

現在能率は参考値です。計画用の能率に採用するときだけ、行ごとに反映します。

  1. 現在能率に数値がある行で、反映 を押します。空（—）の行は押せません。
  2. 「現在能率 ○○.○ を能率に反映しますか？」と出ます。
  3. 反映 で、その行の能率だけが現在能率と同じ値になります。現在能率の数値はそのまま残ります。

複数行を一括で反映する機能はありません。採用する行だけを確認して反映してください。

9. 生産性から組み合わせを追加する

各工程の生産性に実績があるのに、設備能率マスタに同じ組み合わせが無いとき、その組み合わせを新しい行として追加します。

  1. 生産性から追加 を押します。
  2. 未登録が無いときは「未登録の組み合わせはありません」と出て、ダイアログは開きません。
  3. 候補があるとダイアログ「生産性から追加」が開きます。初期状態ではすべての行にチェックが付いています。
  4. 不要な行のチェックを外します。画面下に「選択 ○ / ○ 件」と出ます。
  5. 選択した組み合わせを追加 を押します。「○ 件を追加しました」と出れば完了です。

9.1 ダイアログの列

列内容
工程切断 / 面取 / 成型 / 溶接 / 検査
設備 / 検査員設備名と設備 CD。検査は検査員氏名と INSP- コード
製品 CD / 製品名製品マスタにある製品だけが候補になります
実績数期間内の実績数量の合計
作業時間(h)期間内の作業時間の合計（時間）
実績件数集計に使ったレコード数。3 件未満は黄色のラベル
能率追加後に能率と現在能率の両方へ入る値

9.2 追加される行の中身

  • 能率と現在能率は同じ値（実績数 ÷ 作業時間 × 95%、小数第 1 位）です。
  • 状態は有効です。単位は空です。
  • 段取時間は、同じ設備 CD ですでに登録されている段取時間のうち、いちばん多い値をコピーします。その設備に既存行が無いときは空です。
  • 備考は「生産性より自動追加（開始日〜終了日）」です。
黄色ラベル（実績 3 件未満）は能率が振れやすいです。 検査は候補が多く、初期状態ですべて選択されています。工程や製品で内容を見てから、不要な行のチェックを外して追加してください。一度に数百件を追加しない運用を推奨します。

9.3 ダイアログ下の注記

  • 製品マスタに無い製品 CD は候補に入りません。コードの一覧が注記されます。
  • 設備マスタに一致しないライン も追加できません。生産性側のライン名と、設備マスタの設備名が一致しないときです。成型のライン名末尾の「号」（成型01号）は、照合のとき「成型01」として扱います。

10. 工程別一覧

ツールバーの 工程別一覧 で開きます。タイトルは「工程別一覧（設備別 製品・能率・使用材料）」です。1 設備が 1 枚のカードになり、カード内は製品名・能率・使用材料の 3 列です。

10.1 一覧に出る行 / 出ない行

条件一覧
状態が有効出る
状態が無効出ない
製品区分が試作品、補給品出ない
設備名に「成型」と「NC」の両方を含む（成型 NC）出ない

メイン画面の一覧には、無効行や試作品もそのまま出ます。除外されるのは工程別一覧だけです。

10.2 使用材料

製品マスタの材料コードを優先します。材料コードが空の製品は、状態が active の製品 BOM 明細にある材料を、行番号順に並べます。材料マスタに名称があれば名称を表示します。

10.3 ダイアログ内の操作

  • 工程のラジオ（全て / 切断 / 面取 / 成型 / 溶接 / メッキ / 検査 / その他）で切り替わります。開いた直後は、メイン画面で選んでいた工程です。
  • キーワードは製品名・設備名の検索です。メイン画面の絞り込みとは独立しています。
  • 右上に「設備 ○ 台 ／ 製品 ○ 件」と出ます。
  • 印刷（A3横） は、エクスポート権限があるときだけ出ます。用紙は A3 横、1 行にカード 6 枚です。工程が複数あるときは工程ごとに改ページします。

11. 一覧の印刷

ツールバーの 印刷 は、メインの一覧を印刷します。工程別一覧の印刷とは別です。

  1. タブと絞り込みを、出したい範囲に合わせます。
  2. 印刷 を押します。対象が 0 件だと「印刷対象の行がありません」と出ます。
  3. 別ウィンドウが開き、ブラウザの印刷ダイアログが出ます。用紙は A4 縦です。

見出しは「設備能率管理（絞込結果）」です。キーワード、設備、製品、工程、件数、印刷日時が付きます。本文は設備ごとにまとまり、列は製品 CD、製品名、能率、段取、状態、備考です。ポップアップがブロックされると「ポップアップがブロックされました」と出ます。ブラウザでこのサイトのポップアップを許可してください。

12. Excel 出力

  1. タブと絞り込みを、出したい範囲に合わせます。
  2. Excel出力 を押します。0 件のときは「出力対象の行がありません」と出ます。
  3. 完了すると「○ 件を Excel に出力しました」と出て、.xlsx がダウンロードされます。

ファイル名の例: 設備能率管理_成型_20261009_0905.xlsx（工程名と年月日時分）。シート名は「設備能率_工程名」です。ヘッダー行は太字です。

13. 現在能率の計算方法

現在能率 ＝（期間内の実績数量の合計 ÷ 期間内の正味作業時間の合計）× 0.95

小数第 1 位で四捨五入します。日ごとの能率を平均した値ではありません。生産性分析画面の総合能率と同じく、期間合計どうしで割ります。

13.1 期間

実行日が属する月を含む、直近 3 カレンダー月です。開始日はその 3 か月前の月の 1 日、終了日は実行日です。

13.2 集計に入れる実績

実績数量が 0 より大きく、作業時間も 0 より大きいレコードだけを分子・分母に入れます。

工程元データ設備の取り方数量時間
切断切断の生産指標ライン名。末尾の「号」は除いて設備名と照合実績数量作業時間
面取面取の生産指標同上合計生産数が 0 より大きければその値。そうでなければ面取実績と SW 実績の合計作業時間
成型成型の生産指標同上（成型01号 → 成型01）実績数量作業時間
溶接溶接実績溶接機。生産完了の行だけ生産実績数正味生産秒を時間に換算
検査検査実績設備は使わない。検査員を 1 台の設備として扱う。生産完了の行だけ生産実績数正味生産秒。無ければ開始〜終了の秒数
メッキ集計しません。既存行の現在能率も変更しません

13.3 検査員の行

  • 設備 CD は INSP- ＋ユーザーの社員番号（ログイン ID）です。例: 社員番号 3001 → INSP-3001。
  • 設備名は氏名です。氏名が空のときは社員番号です。
  • このコードで始まる行は、設備名に「検査」と無くても検査タブに分類されます。
  • 検査員の行は、設備マスタの設備とは別のコードです。成型や溶接の設備行と混ざりません。

13.4 既存行との突き合わせ

  • 切断・面取・成型・溶接は、正規化した設備名と製品 CD で既存行に当てます。
  • 検査は設備 CD（INSP-…）と製品 CD で当てます。
  • 当たった行は現在能率と更新日時を書き換えます。当たらず、かつその工程の集計に成功している行は、現在能率を空にします（実績なし）。
  • メッキ、および集計できなかった工程の行はスキップし、既存の現在能率を残します（対象外）。

14. 工程の自動判定

タブ、工程別一覧、Excel の工程列、現在能率の対象判定は、同じルールです。上から順に、最初に一致した工程になります。

順条件工程
1設備 CD が INSP- で始まる検査
2設備名または設備 CD に「面取」または chamfer面取
3「成型」または forming成型
4「溶接」または welding溶接
5「メッキ」、plating、または設備 CD に plメッキ
6「検査」または inspection検査
7「切断」または cutting切断
8どれにも一致しないその他

設備名の表記がこのルールと違うと、意図したタブに出ません。その場合は設備マスタの名称を確認してください。

15. 権限

ボタンと行操作は、マスタ画面の操作権限で出します。

権限できる操作
参照一覧、絞り込み、工程別一覧の表示
登録新規登録、生産性から追加
編集編集、状態の切替、現在能率更新、反映
削除削除
エクスポート印刷、Excel出力、工程別一覧の印刷

権限が無い操作を実行しようとすると、操作ガードのメッセージが出て処理は始まりません。

メッセージ意味と対処

17. 運用上の注意

  1. 更新と反映を分けてください。 月初などに「現在能率更新」で参考値を作り、差が大きい行だけを担当者が「反映」します。更新ボタンだけでは計画用の能率は変わりません。
  2. メッキは自動計算しません。 メッキの能率は、新規登録または編集で手入力します。
  3. 検査は検査員単位です。 検査工程に設備列は無いため、検査員 × 製品で行を持ちます。設備 CD は INSP- で始まります。工程別一覧や Excel でも、設備名の位置に検査員氏名が出ます。
  4. 実績が少ない行は採用前に確認してください。 件数が 1〜2 件だと、1 件の異常な作業時間で能率が極端に低く、または高くなります。黄色ラベルの行は、反映や追加の前に生産性の元データを見てください。
  5. 生産性から追加は全選択が初期値です。 検査だけでも候補が数百件になることがあります。必要な組み合わせだけ残して追加してください。追加した行の能率は、最初から現在能率と同じ値です。あとから現在能率更新をしても、能率は自動では追従しません。
  6. ライン名と設備名を揃えてください。 一致しないラインは追加も現在能率の更新もできません。成型の「号」だけは自動で無視します。
  7. 工程別一覧は配布用の見え方です。 無効、試作品、補給品、成型 NC はカードに出ません。マスタの全件を渡すときは、メイン画面の Excel 出力を使ってください。
  8. 印刷と Excel は絞り込み全件です。 画面が 20 件表示でも、条件に合う行が 500 件あれば 500 件出ます。出す前にタブと設備・製品を確認してください。

以上。本書の対象は設備能率管理画面（2026年10月9日時点）です。計画画面側で能率をどう工数に換算するかは、各計画画面の説明に従ってください。
