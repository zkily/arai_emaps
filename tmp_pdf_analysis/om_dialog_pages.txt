8-2 一覧に出る製品と列
製品マスタで、選んだ納入先にひもづく有効な製品が出ます。補給品・試作品は出ません。並びは製品名順です。
状態：同じ年月・納入先名・製品名の月受注がすでにあれば 登録済、無ければ 新規。
数量：登録済の行には、いまの内示本数が入っています。数量が空または 0 の行は黄色、入っている行は緑色です。
8-3 何が登録・更新されるか
行の状態
登録する を押したとき
新規・数量 1 以上
月受注を新しく作ります（確定本数 0）
登録済・数量を変えた
内示本数だけを新しい数量に更新します
登録済・数量を変えていない
何もしません
数量が空または 0
何もしません（登録済の内示本数も 0 にはなりません）
注意
年・月を変えたら、必ずもう一度「読込」を押してください。納入先を変えると一覧は消えますが、年月を変えただけでは前の一
覧が残り、状態・数量は前の年月のままです。
内示を 0 にしたいときは、一括登録ではなく、一覧の「編集」で 0 にするか「削除」してください。
一括登録は月受注だけを作ります。日受注は作りません。登録後に日受注生成を行ってください。
状態は納入先名・製品名で判定します。製品マスタで名称を変えたあとは、先に製品更新を行ってください。名称が違うと「新
規」と判定され、登録時に重複としてスキップされます（「○件スキップ」）。
